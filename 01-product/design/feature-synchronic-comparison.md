## 0. 一句话概念

> 一条贯穿东西方的纵向时间轴，配一根可上下拖动的「时间游标」。游标扫到哪一年，
> 左（西方）右（东方）两栏就**同时点亮**那一刻在世的思想家——
> 让人亲眼看到「苏格拉底诘问雅典时，孔子正周游列国」。

设计目标：把"一份哲学家名单"变成"一场跨越文明的同期对话"。**对照感 = 记忆点。**

## 1. 信息分层（三层渐进披露）

沿用你的分层设想，叠加"同期对照"这条横向线索：

| 层 | 看到什么 | 触发 |
|---|---|---|

## 2. 界面框架（线框示意，非视觉稿）

整体是「**中轴计时 + 东西双栏**」结构（呼应原 PDF 与世界史参考图的并行色块）：

```
┌────────────────────────────────────────────────────────────────┐
│  NAV   全球思想对照时间线        [时代跳转 古·中·近·现]   [搜索]    │ ← 顶部导航
├──────────────┬───────────────┬───────────────┬─────────────────┤
│   西方 WEST   │   时间轴 Y    │   东方 EAST    │                 │
│              │               │ (朝代色块背景)  │                 │
│ ▓ 米利都学派  │  前600 ─────  │               │                 │
│   ◉泰勒斯    │               │               │                 │
│   ◉阿那克西.. │  前550 ─────  │ ▓ 儒家         │                 │
│              │               │   ◉老子        │                 │
│ ▓ 毕达哥拉斯  │  前500 ━━━━━━━━━━━━━━━━━━━━━━━━ ◀ 游标(可拖)  ───┼─→ ┌───────────┐
│   ◉毕达哥拉斯 │  ← 此刻同期 →  │   ◉孔子 ◉孙武   │     │ 同期面板    │
│   ◉赫拉克利特 │               │               │     │ 「前500年」 │
│              │  前450 ─────  │ ▓ 道家         │     │ 西:毕达哥拉斯│
│ ▓ 爱利亚学派  │               │   ◉孔子        │     │   赫拉克利特 │
│   ◉巴门尼德   │  前400 ─────  │               │     │ 东:老子 孔子│
│      ⋮       │      ⋮        │      ⋮        │     │   孙武      │
│              │               │ (东栏留白段)   │     └───────────┘
└──────────────┴───────────────┴───────────────┴─────────────────┘
         ▲ 流派=色带         ▲ 时间标尺          ▲ 留白是历史真实
         ◉ 人物=头像节点                          （东方脉冲式）
```

- **时间轴方向**：纵向，时间从上（前 700）到下（公元 2000）。可缩放（古希腊 200 年可放大）。
- **西方在左、东方在右**，中间共用时间标尺，确保"同一水平线 = 同一年代"。
- **流派**：纵向色带，覆盖其 `start`–`end` 年份区间，宽度内排布该流派人物头像。
- **人物**：头像节点，按 `born` 定位在时间轴上。
- **东方朝代**：作为东栏的**背景色块**（夏→民国），由 events 的"朝代"型数据渲染。
- **游标**：一根横贯东西的水平线，可上下拖动；也可点击时间轴任意处跳到该年。

## 3. 关键交互流程

### 流程 A — 默认浏览（L1）
1. 进入页面 → 看到完整东西双栏时间轴，人物头像浮动其上。
2. 上下滚动 / 缩放浏览不同时代。
3. hover 人物头像 → 浮出 `name` + 生卒 + `summary` 的轻提示（tooltip）。

### 流程 B — 同期对照（核心 ✦）
1. 用户拖动游标（或点击某一年）。
2. **同期判定**：凡 `born ≤ 游标年 ≤ died` 的人物 = "此刻在世"，**高亮**；其余降到低透明度。
3. 弹出**「同期面板」**：顶部大字显示当前年份，下分「西 / 东」两列，列出同期人物（头像 + 名 + 一句 `summary`）。
4. 面板里点任一人 → 进入 L3 人物详情。

> ✦ 这是整个产品的"出片点"。同期面板应可**一键分享/截图**（如"公元前 500 年，东西方都在思考什么"）。

### 流程 C — 轴心时代「开场引导」（建议）
- 首次进入可有一段**自动演示**：游标自动滑到公元前 500 年并停住，同期面板高亮 `老子/孔子 ↔ 毕达哥拉斯/赫拉克利特`，配一句文案："这就是雅斯贝尔斯所说的『轴心时代』——人类几大文明几乎同时觉醒。"
- 用户任意操作即跳出引导，进入自由浏览。

### 流程 D — 流派详情（L2）
- 点流派色带 → 抽屉/卡片展示：`name`(中英) · `description` · `coreThemes` 标签 · `representativePhilosophers` 头像列表。
- 点其中人物 → L3。

### 流程 E — 人物详情（L3）
- 点人物节点 → 展示：`portrait` · `name`/`nameEn` · 生卒（`bornApprox` 为真则前缀"约"）· `nationality` · 所属 `school` · `coreIdeas`(列表) · `majorWorks` · `quote`。

## 4. 数据 → UI 映射（每个界面元素吃哪个字段）

> 数据已就绪于 `02-data/structured/`，字段规范见 `05-docs/data-schema.md`。

| 界面元素 | 数据来源 | 字段 |
|---|---|---|
| 东西分栏归属 | philosophers / schools / eras | `region`（west / east）|
| 人物节点位置 | philosophers | `born`（Y 轴定位）、`died`（同期判定区间）|
| 节点"约"字前缀 | philosophers | `bornApprox` / `diedApprox` |
| 节点头像 | philosophers | `portrait.url`（⚠️ 目前为空，见 §6）|
| hover 轻提示 | philosophers | `name` + 生卒 + `summary` |
| 流派色带颜色/区间 | schools | `color` · `start` · `end` |
| 流派色带内人物 | schools | `representativePhilosophers`（人物 id）|
| 流派详情(L2) | schools | `name` `nameEn` `description` `coreThemes` |
| 人物详情(L3) | philosophers | `coreIdeas` `majorWorks` `quote` `nationality` `type` |
| 时代分段/背景 | eras | `name` `start` `end` `color`（西 4 时代 / 东 7 断代）|
| 时代跳转导航 | eras | `name` + `start`（点击滚动定位）|
| 东方朝代背景块 | events(`type=朝代`) | `name` `year`(起) `endYear`(止) |
| 思想史节点标记 | events(`type=思想/文化`) | `year` `name` `description` |
| 同期面板成员 | 计算 | 遍历 philosophers 取 `born≤Y≤died` |

**人物类型图标**（P1）：philosophers `type`（哲学家/科学家/文学家/神学家/军事家）。

## 6. 状态与边界情况（必须在设计里处理）

| 情况 | 说明 | 设计建议 |
|---|---|---|
| **东栏留白** | 东方思想史脉冲式，东西同期重叠仅约 33% | 把留白当"呼吸"，或在空段显示朝代背景块维持视觉连续，避免"坏掉"的观感 |
| **同期面板某侧为空** | 如某年仅西方有人 | 空侧给一句温和文案（如"此时东方正处○○朝，思想沉潜期"），而非空白 |
| **画像缺失** | `portrait.url` 现全为空 | 需占位设计：首字/剪影/统一插画风头像。**这关系到 L1 浮动头像的视觉**，建议你在 Figma 先定头像展示形态，我再据此批量补 URL |
| **近似年份** | `bornApprox=true` | 年份前显示"约" |
| **生卒跨公元** | 负数=公元前 | 标尺与节点需正确处理 BCE/CE |
| **缩放密度** | 轴心时代人物密集、中世纪稀疏 | 缩放时节点防重叠（聚合/错位）|
| **移动端** | P1 响应式 | 双栏在窄屏如何退化（上下堆叠？切换东/西？）待定 |

## 7. 留给设计师的开放决策清单（Figma 里要定）

这些我故意不替你定，等你的原型：

1. **L2/L3 呈现方式**：侧边抽屉 / 覆盖卡片 / 就地展开？返回上层的手势？
2. **同期面板形态**：固定侧栏 / 跟随游标的浮卡 / 底部抽屉？
3. **游标交互**：常驻可拖 / 还是 hover 时间轴即时对照？是否要"锁定某年"再细看？
4. **东西布局**：左右分栏（推荐）/ 还是其他？窄屏如何退化？
5. **头像展示**：真实画像 / 统一插画 / 剪影占位？浮动是常显还是 hover 才现？
6. **留白处理**：东栏空段如何既诚实又不显得"残缺"？
7. **轴心时代开场**：要不要自动引导演示？强度如何？
