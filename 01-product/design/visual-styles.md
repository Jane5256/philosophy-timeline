## 风格 A — 「古典手稿」Manuscript

**关键词**：羊皮纸、学术、温暖、书卷气、历史感

### 配色体系

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | `#F5ECD7` | 暖米色，仿羊皮纸 |
| 卡片背景 | `#EFE3C8` | 略深米色 |
| 主文字 | `#2C1810` | 深褐色 |
| 次级文字 | `#6B4C35` | 中褐色 |
| 时间轴主线 | `#8B4513` | 棕红色 |
| 强调色 | `#C4873A` | 赭金色 |
| 古代流派 | `#C4873A` | 赭黄 |
| 中世纪流派 | `#7A6E9E` | 暗紫 |
| 近代流派 | `#4A7E5E` | 深绿 |
| 现代流派 | `#3D6B8E` | 蓝灰 |

### 字体

| 用途 | 字体 | 说明 |
|------|------|------|
| 大标题 | Playfair Display | 经典衬线，历史感强 |
| 中文正文 | Noto Serif SC / 思源宋体 | 宋体风格，书卷感 |
| 英文正文 | EB Garamond | 古典英文衬线 |
| 年份/标注 | Playfair Display Italic | 斜体强调 |

### 视觉特征

- 卡片有轻微纸张纹理（CSS 或 SVG 滤镜实现）
- 哲学家画像用椭圆相框，带细边框装饰
- 时间轴线条为手绘感虚线（`stroke-dasharray`）
- 节点为圆形印章风格，hover 有蜡封展开动效
- 分隔线使用装饰性细线（类似书籍扉页）
- 历史事件用小羽毛笔图标标注

### 适用用户

喜欢人文感、书卷气、阅读感强的用户；适合内容消费型场景

## 风格 B — 「现代极简」Minimal Dark

**关键词**：深色、数据可视化、科技感、专注内容

### 配色体系

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | `#0F1117` | 近黑，深蓝调 |
| 卡片背景 | `#1A1D27` | 深蓝灰 |
| 次级背景 | `#242736` | 悬停/激活状态 |
| 主文字 | `#E8E8E8` | 浅灰白 |
| 次级文字 | `#8A8FA8` | 中灰蓝 |
| 时间轴主线 | `#FFFFFF` | 纯白细线 |
| 强调色 | `#7C6AF7` | 紫罗兰 |
| 古代流派 | `#F4A261` | 暖橙 |
| 中世纪流派 | `#9B5DE5` | 紫色 |
| 近代流派 | `#00B4D8` | 青蓝 |
| 现代流派 | `#06D6A0` | 薄荷绿 |

### 字体

| 用途 | 字体 | 说明 |
|------|------|------|
| 大标题 | Inter / SF Pro Display | 现代无衬线 |
| 中文正文 | Noto Sans SC / 思源黑体 | 清晰易读 |
| 英文正文 | Inter | 统一无衬线 |
| 代码/年份 | JetBrains Mono | 等宽，数字对齐 |

### 视觉特征

- 哲学家节点发光效果（`box-shadow` 光晕），hover 光圈扩散
- 流派色带为半透明渐变条（`opacity: 0.25`），选中后加深
- 详情卡片从右侧滑入，带毛玻璃效果（`backdrop-filter: blur`）
- 历史事件为时间轴左侧的彩色菱形图标
- 搜索结果高亮用紫色外发光
- 整体风格类似 Linear、Vercel、Raycast

### 适用用户

习惯深色模式、数据可视化工具的用户；适合夜间阅读、长时浏览

## 风格 C — 「博物馆展陈」Museum

**关键词**：白色、高雅、图文并重、机构感、学术权威

### 配色体系

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | `#FAFAFA` | 近白 |
| 卡片背景 | `#FFFFFF` | 纯白 |
| 分区背景 | `#F0F0EE` | 极浅暖灰 |
| 主文字 | `#1A1A1A` | 近黑 |
| 次级文字 | `#5C5C5C` | 中灰 |
| 时间轴主线 | `#1A1A1A` | 黑色粗线 |
| 古代流派 | `#D4A853` | 金色 |
| 中世纪流派 | `#6B4E8A` | 王室紫 |
| 近代流派 | `#2E7D5E` | 翡翠绿 |
| 现代流派 | `#1565C0` | 皇家蓝 |
| 强调/警示 | `#C62828` | 朱红（重要节点） |

### 字体

| 用途 | 字体 | 说明 |
|------|------|------|
| 大标题 | DM Serif Display | 优雅高对比衬线 |
| 中文正文 | Noto Serif SC / 思源宋体 | 庄重感 |
| 英文正文 | DM Sans | 现代感，与衬线标题形成对比 |
| 标注/说明 | DM Sans Italic | 斜体辅助 |

### 视觉特征

- 哲学家画像大图展示，卡片如博物馆说明牌（带黑色边框标题栏）
- 时间轴为黑色竖线，哲学家节点为方形章节感标记
- 大量留白，内容间距宽松
- 流派标题用全大写英文 + 中文副标题
- 历史事件用细横线 + 简短标注
- 整体风格类似 MoMA 官网、大英博物馆数字展览、纽约时报长文排版

### 适用用户

希望兼顾学术感与传播性的用户；适合图文内容展示、分享截图
