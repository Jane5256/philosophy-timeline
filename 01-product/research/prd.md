# 产品需求文档（PRD）
> 西方哲学史可交互可视化网站

版本：v0.1
日期：2026-06-04
状态：待确认

---

## 一、产品定位

> **一款以西方哲学史为内容核心的中文交互式时间轴网站**，面向对哲学感兴趣的大众读者，以年代为主轴，将哲学家、流派、历史背景编织成可探索的知识地图。

| 项目 | 说明 |
|------|------|
| **目标用户** | 对哲学有基础兴趣的中文读者（大学生、文史爱好者、知识付费用户） |
| **非目标用户** | 专业哲学研究者（内容深度暂不满足学术需求） |
| **核心价值** | 让哲学史变得可视化、可探索、中文友好 |
| **差异化** | 哲学 + 历史双轨并行；中文优先；数据驱动可扩展 |

---

## 二、功能需求

### P0 — MVP 核心功能（第一版必须完成）

| # | 功能 | 描述 |
|---|------|------|
| F01 | **纵向时间轴** | 以年代为 Y 轴，展示公元前 600 年 → 公元 2000 年 |
| F02 | **流派色带** | 每个哲学流派对应独立颜色，覆盖其活跃年份区间 |
| F03 | **哲学家节点** | 按生年在时间轴上定位，显示头像缩略图和姓名 |
| F04 | **详情卡片** | 点击节点展开：画像、姓名（中英）、生卒年、流派、核心思想、代表作、名言 |
| F05 | **历史事件轨道** | 时间轴侧边显示重大历史事件，支持政治/科学/宗教/文化分类 |
| F06 | **流派筛选** | 点击流派标签，高亮该流派所有节点，其余节点半透明 |
| F07 | **时代跳转导航** | 顶部导航：古代 / 中世纪 / 近代 / 现代，点击滚动定位 |

### P1 — 核心体验增强（第二阶段）

| # | 功能 | 描述 |
|---|------|------|
| F08 | **搜索** | 支持中文名 / 英文名 / 著作名模糊搜索，结果高亮并滚动定位 |
| F09 | **人物类型标识** | 哲学家 / 科学家 / 文学家 / 神学家用不同图标区分 |
| F10 | **时间轴缩放** | 支持区间缩放（如单独查看古希腊 200 年范围） |
| F11 | **响应式布局** | 桌面端：左轴右卡；移动端：全屏纵向滚动 |
| F12 | **亮/暗模式切换** | 支持系统跟随 + 手动切换 |

### P2 — 后续迭代（三期及以后）

| # | 功能 | 描述 |
|---|------|------|
| F13 | **关系图谱页** | 独立页面，力导向图展示哲学家影响关系网络 |
| F14 | **流派对比** | 同屏对比两个流派的核心主张 |
| F15 | **内容扩展入口** | 通过编辑 JSON 文件新增哲学家/流派，无需改代码 |
| F16 | **多语言支持** | 界面支持中文 / 英文切换 |

---

## 三、非功能需求

| 指标 | 要求 |
|------|------|
| **性能** | 首屏加载 < 3 秒；滚动帧率 ≥ 60fps |
| **扩展性** | 新增哲学家/流派只需编辑 JSON，无需改业务代码 |
| **可维护性** | 数据与 UI 完全解耦，JSON 文件是唯一内容来源（Single Source of Truth） |
| **部署** | 纯静态站，可部署至 GitHub Pages / Vercel / 任意 CDN |
| **浏览器兼容** | Chrome / Safari / Firefox 最新两个版本 |

## 四、信息架构

```
网站
├── 主页（时间轴）                    ← 核心页面，P0
│   ├── 顶部导航栏
│   │   ├── 时代 Tab（古代/中世纪/近代/现代）
│   │   ├── 流派筛选下拉
│   │   └── 搜索框
│   ├── 时间轴主体
│   │   ├── 左侧：年份刻度 + 历史事件轨道
│   │   ├── 中轴：流派色带（彩色时间区间）
│   │   └── 右侧：哲学家节点（头像 + 姓名）
│   └── 详情面板（点击节点滑入）
│       ├── 画像
│       ├── 基本信息（姓名/生卒/国籍/流派）
│       ├── 核心思想（要点列表）
│       ├── 代表作
│       └── 名言
│
├── 流派总览页（P1）
│   └── 网格卡片，按时代分组
│
└── 关系图谱页（P2）
    └── 力导向影响关系图
```

## 五、数据架构

数据文件位于 `02-data/structured/`，JSON 格式，数据与代码解耦：

```
structured/
├── eras.json           # 时代分期（古代/中世纪/近代/现代）
├── schools.json        # 哲学流派
├── philosophers.json   # 哲学家（核心文件）
├── events.json         # 历史背景事件
└── relations.json      # 影响关系（P2 阶段使用）
```

字段规范见：`05-docs/data-schema.md`
